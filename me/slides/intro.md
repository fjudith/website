# What is this?

This deck is authored in Markdown with [Slidev](https://sli.dev) and built to
a static site during `npm run build`.

- 📝 **Markdown-based** — write slides as text
- 🎨 **Themeable** — powered by Vue and UnoCSS
- 🧑‍💻 **Developer-friendly** — code blocks, diagrams, embeds
- 🔗 **Embeddable** — served from `/slides/intro/` and framed in the docs
